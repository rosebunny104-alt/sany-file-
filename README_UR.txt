APK بنانے کا طریقہ (GitHub سے، مفت)
1) github.com پر اکاؤنٹ بنائیں، New repository بنائیں (Private ٹھیک ہے)۔
2) اس زپ کی تمام فائلیں (.github فولڈر سمیت) repository میں اپلوڈ کریں۔
3) Actions ٹیب > "Build APK" > Run workflow دبائیں۔ 5-8 منٹ لگیں گے۔
4) ختم ہونے پر نیچے Artifacts سے "100K-Goal-APK" ڈاؤن لوڈ کریں، زپ کھولیں، app-debug.apk نکالیں۔
5) Samsung پر apk کھولیں > "Install unknown apps" کی اجازت دیں > Install۔

ڈیٹا: ایپ فون میں محفوظ رہتی ہے۔ Sheet ٹیب میں Backup دبا کر باقاعدگی سے JSON فائل محفوظ کریں (WhatsApp/Drive پر)، اور Restore سے واپس لائیں۔
